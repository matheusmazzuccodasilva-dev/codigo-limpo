# Resumo - capitulos 2,4 e 5 do livro código limpo.
O livro Código Limpo: Habilidades Práticas do Agile Software, de Robert C. Martin, apresenta práticas fundamentais para desenvolver softwares mais organizados, legíveis e fáceis de manter. Nos capítulos 2, 4 e 5, o autor aborda temas essenciais como nomes significativos, comentários e formatação do código.
# Capitulo 2 - Nomes significativos
O autor destaca a importância de utilizar nomes claros e descritivos para variáveis, funções e classes. Nomes bem escolhidos facilitam a compreensão do código e reduzem a necessidade de explicações adicionais.
#### Importância: Melhora a legibilidade e facilita a manutenção do software.
# Capitulo 4 - Comentários
Robert C. Martin afirma que comentários não devem compensar um código mal escrito. O ideal é que o próprio código seja claro e autoexplicativo. Comentários devem ser usados apenas quando realmente necessários.
#### Importância: Evita confusão e torna o código mais fácil de entender e atualizar.
# Capitulo 5 - Formatação
A formatação do código influencia diretamente sua leitura. O autor recomenda manter padrões consistentes, utilizar espaçamentos adequados e organizar o código de forma lógica.
#### Importância: Facilita a compreensão, manutenção e trabalho em equipe.
# Conclusão
Os três capítulos mostram que um código limpo deve ser fácil de ler e entender. Utilizar nomes significativos, evitar comentários desnecessários e manter uma boa formatação são práticas essenciais para desenvolver softwares de qualidade e mais fáceis de manter.
